# Smart Home ІКС

Інтелектуальна система керування мікрокліматом і енергоощадженням розумного будинку.
Навчальний проєкт з дисципліни «Інтелектуальні комп'ютерні системи», виконує Кодовбецька В. І., група ІАВ-21.

## Структура

```
data/            база знань
  rules.json         10 продукційних правил з ПР3 (salience, вага, умови, дії)
  facts.json         база фактів з ПР2 у форматі «об'єкт – атрибут – значення»
  initial_state.json початковий стан пристроїв і режиму
  scenarios.json     тестові ситуації
  fuzzy_vars.json    лінгвістичні змінні та функції належності (ЛР2)
  rules_fuzzy.json   ті самі правила з нечіткими умовами (ЛР2)
  scenarios_fuzzy.json  ситуації з невизначеністю (ЛР2)
engine/          ядро rule-based системи (ЛР1)
  working_memory.py  робоча пам'ять
  rules.py           завантаження правил і перевірка умов
  inference.py       механізм виведення (прямий ланцюжок)
fuzzy/           нечітка логіка й коефіцієнти впевненості (ЛР2)
  membership.py      функції належності
  certainty.py       обчислення CF
  memory.py          робоча пам'ять з CF
  inference.py       виведення з невизначеністю
main.py          запуск ЛР1
lr2.py           запуск ЛР2
plot_terms.py    графіки функцій належності (потрібен matplotlib)
reports/         звіти
```

## Запуск

Потрібен лише Python 3.10+ (сторонні бібліотеки не потрібні).

```
python main.py                 # усі сценарії
python main.py -s 3            # один сценарій
python main.py -s 3 --explain  # з поясненням, чому правила не спрацювали
python main.py -f data/facts.json

python lr2.py                  # ЛР2, усі сценарії з невизначеністю
python lr2.py -s 2 --compare   # порівняння з чіткою системою ЛР1
```

На macOS замість `python` пишіть `python3`.
